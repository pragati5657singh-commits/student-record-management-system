# student-record-management-system
The Student Record Management System is a C++-based project that uses Object-Oriented Programming (OOP) concepts to manage student information efficiently. It allows users to add, view, search, update, and delete student records. The system uses file handling to store records permanently, making student data easy to access and manage.
The main aim of this project is to reduce manual work, improve accuracy, save time, and make student record management simple, reliable, and efficient.
